# Dev's Cake Lab

Vite + React frontend for Dev's Cake Lab.

```bash
npm install
npm run dev
```

## GitHub Pages

The live site must be the **Vite build**, not the source `index.html`. After pushing `main`, set:

**Settings → Pages → Source → GitHub Actions**

The site will be at [https://kira262.github.io/dev-cake-lab/]`(https://kira262.github.io/dev-cake-lab/)`.
